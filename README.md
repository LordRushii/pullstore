# Pullstore E-commerce

Modern e-commerce application built with React, Vite, and MongoDB.

## Quick Start

```bash
npm install
npm run dev
```

## Environment Variables

Create `.env` file:

```env
VITE_MONGO_URI=your_mongodb_connection_string
VITE_BETTER_AUTH_SECRET=your_secret_key
VITE_BETTER_AUTH_URL=http://localhost:5173
VITE_APP_URL=http://localhost:5173
```
